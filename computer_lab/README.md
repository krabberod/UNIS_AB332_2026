R scripts for the computer lab exercises.
The exercises are divided into four parts:
Rmd files are Rstudio markdown files that can be opened and run in Rstudio (and similar IDEs).
R files are standard R scripts that can be run in any R environment.
1) [Diversity indices and rarefaction](Computer_lab_I.Rmd)
2) [Ordination methods and clustering](Computer_lab_II.Rmd)
3) [Environmental fitting and constrained ordination](Computer_lab_III.Rmd)
4) [Taxonomic distributions](Computer_lab_IV-taxonomic_analysis_tidyverse.R)
